🌑 按胆量

先问自己：今晚敢不敢一个人看。

  • 敢 → 犯罪/硬核纪实
  • 一般 → 悬疑烧脑
  • 不敢 → 动作爽片（别选恐怖）

⏳ 按时长

深夜时间贵，别开 3 小时史诗。

  • 90 分钟 → 悬疑/动作
  • 120 分钟 → 犯罪/黑帮
  • 150+ 分钟 → 留到周末

🔊 按声音

合租/卧室/地铁，声音策略不同。

  • 戴耳机 → 悬疑/纪实
  • 外放别扰民 → 动作/喜剧
  • 静音看字幕 → 烧脑片

🧠 按脑力

下班累成狗就别硬啃诺兰。

  • 放空 → 追车/枪战
  • 微动脑 → 犯罪群像
  • 全速 → 记忆碎片/前度
